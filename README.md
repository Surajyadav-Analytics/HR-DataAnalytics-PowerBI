# 📊 HR Data Analytics Dashboard | Power BI

### 🚀 Transforming HR Data into Meaningful Insights

## 📌 Project Overview
An interactive **HR Analytics Dashboard** built using Microsoft Power BI to analyze employee data, explore hiring trends, and gain insights into workforce demographics.

## ✨ Key Features
- 📈 **Hiring Trend Analysis** — Analyze employee hiring patterns.
- 👥 **Employee Details** — Explore employee information and workforce data.
- 🏢 **Department Analysis** — Navigate department-level insights using drill-through.
- 🎛️ **Interactive Filters** — Explore data dynamically through slicers and visualizations.
- 📊 **Data Visualization** — Present HR insights through interactive charts and reports.

## 🛠️ Tools & Technologies
- 📊 Microsoft Power BI
- 🔄 Power Query
- 🧮 DAX (Data Analysis Expressions)

## 🎯 Project Objective
To transform raw HR data into meaningful insights through interactive visualizations, supporting workforce analysis and data-driven decision-making.
